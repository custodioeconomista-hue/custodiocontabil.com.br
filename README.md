# Custódio Contábil — site institucional

Site estático em HTML, CSS e JavaScript, preparado para GitHub Pages.

## Publicação
1. Crie um repositório público chamado `custodio-contabil-site`.
2. Extraia todos os arquivos deste ZIP.
3. Envie `index.html`, `styles.css`, `script.js`, `README.md` e a pasta `assets` para a raiz do repositório.
4. No GitHub, abra **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.

Depois de publicar, configure o domínio `custodiocontabil.com.br` na área **Custom domain** do GitHub Pages e ajuste os registros DNS no Registro.br conforme as instruções oficiais do GitHub.
